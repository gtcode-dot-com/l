# Image masters — source notes

All three files in this directory are **editorial illustrations generated for these articles**, not documentary photographs or evidence of any reported event. They are intended as full-quality source masters for the existing GTCode/Hugo image pipeline.

## Master specification

- Dimensions: **2400 × 1260 px**
- Aspect ratio: **40:21** (approximately 1.90:1)
- Format: **lossless PNG**
- Color: **sRGB** (embedded profile)
- Orientation: landscape
- Embedded headline/text: none intentionally added
- Distribution derivatives: **not included**; generate them with the repository's current scripts/process from these masters
