# Corruption normalization source packet

Retrieved October 6, 2026. The manifest records original URLs, preservation status, and SHA-256 hashes. PDFs and Civil Beat HTML files are source copies. Academic JSON files are citation metadata, not full-text archives. DOJ direct downloads returned access-check pages; those pages were discarded and replaced with explicitly labeled citation records after verification through web retrieval. Oxford blocked direct download (HTTP 403); its publisher abstract was verified and citation metadata preserved.

Research correction: Neshkova and Kalesnikaite (2019) found participation positively related to experienced corruption, but not perceived corruption. The abstract’s discussion of cynicism is not its empirical finding. This packet does not support a universal corruption-perception-to-disengagement claim.
