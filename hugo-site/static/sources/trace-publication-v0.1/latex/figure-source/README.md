# Rebuild the conceptual figures

The original CNS figure layouts are generated by `render_figures.py`. No experimental data are plotted. The scientific claims and manuscript captions remain unchanged.

Typography, palette and vector-export conventions follow the design guidance in [Chen Liu's figures4papers](https://github.com/ChenLiu-1996/figures4papers), especially `scientific-figure-making/references/design-theory.md` and `api.md`. This is a custom Matplotlib drawing implementation; no third-party figure artwork or project data are redistributed.

From the manuscript source directory:

```sh
python3 -m venv .figure-env
.figure-env/bin/pip install matplotlib==3.11.2
.figure-env/bin/python figure-source/render_figures.py
```

The script writes three SVGs with editable text and three vector PDFs into `figures/`. DejaVu Sans is supplied with Matplotlib; no proprietary fonts, LaTeX renderer, image generator, or network calls are needed once the dependency is installed. The normal manuscript build uses the pre-exported PDFs and does not require Python.

For site maintenance, copy these six files to `hugo-site/static/papers/trace/figures/`, rebuild the manuscript PDF with `sh build.sh`, repack the standalone source ZIP, and refresh the publication manifest and checksums. Keep the source archive free of `.figure-env`, build logs and TeX auxiliary files.
